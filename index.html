UM GUIA PARA A COMUNIDADE

Informação acessível faz diferença.

O Realeza Conecta é uma proposta de guia digital para reunir atalhos de informações úteis do município. A ideia é facilitar a busca por contatos e serviços, principalmente para quem acessa a internet pelo celular.

O projeto é complementar: para confirmar horários, documentos e possíveis mudanças, consulte sempre os canais oficiais.
